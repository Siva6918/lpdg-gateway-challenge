# LPDG Innovation Hub Selection Challenge 2026

## Project Setup

This repository is being developed as part of the **LPDG Innovation Hub Selection Challenge 2026**.

The project will use gateway telemetry data to identify and rank the gateways that should be considered for field visits.

## Challenge

The operations team can perform a maximum of **15 field visits per week**. The goal is to build a system that ranks gateways based on their telemetry behaviour and provides a reason for each recommendation.

The challenge consists of:

- **Part 1:** Gateway ranking and predictions
- **Part 2:** A selected technical area

For Part 2, **Software Development** has been selected.
